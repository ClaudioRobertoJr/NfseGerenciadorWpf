# Importação nacional e distribuição online

Objetivo autorizado: integrar a API ADN ao WPF existente, importar somente emissões do CNPJ informado desde 01/11/2026, preservar baixas e publicar atualização para outra máquina.

Arquitetura: HttpClient com certificado Windows A1/A3; parser nacional separado do municipal; estado NSU e chave nacional no SQL Server, com transação por lote. Não armazenar PIN. Download da versão compilada via GitHub Releases, com script de atualização que preserva appsettings.json e copia versão anterior antes de substituir binários.

- [x] Parser e testes sintéticos: emissão versus DPS, data local, valor líquido, identidade, filtro e cancelamentos.
- [x] Consulta autenticada, erros, paginação e checkpoint transacional; migração aditiva sem alterar pagamentos existentes.
- [x] Janela de importação com seleção de certificado, progresso e cancelamento.
- [ ] Compilar, testar migração/modelo, publicar workflow e release Windows x64.
- [ ] Revisar integridade financeira, retomada, duplicidade e atualização; acompanhar compilação no GitHub.

Limites: token real só está na outra máquina; teste integrado de A3 e SQL real será feito lá. O acesso à API por procuração já foi validado pelo usuário. GitHub não recebe certificados, notas reais, credenciais ou banco de dados.

Revisão: respostas com Erros/LoteDFe nulos normalizadas, com teste de regressão. Data de emissão nacional usa infNFSe/dhProc, mantendo a data local, com teste de DPS de outubro gerada como nota em novembro. Cancelamentos preservam baixas realizadas e retiram apenas previsão em aberto. Build local e publicação self-contained passaram; EF confirmou ausência de mudanças pendentes. Teste do atualizador confirmou preservação da configuração e cópia dos binários anteriores.
